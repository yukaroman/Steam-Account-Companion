# Changelog

All notable release changes are documented here.

## [Unreleased]

- Real-account end-to-end validation for Auth V2 and mobile confirmations.
- Background app-switcher snapshot privacy cover.

## [0.1.0] - 2026-07-18

- Multi-account Steam Guard codes with Steam QueryTime alignment.
- maFile and SteamTools JSON import.
- Local account persistence with optional AES-256-GCM protection.
- Password-encrypted `.sacbak` export and restore.
- Optional Face ID, fingerprint, or device-credential gate.
- Light, dark, system, and OLED themes.
- Experimental Steam Auth V2 session login and mobile confirmations.
- iOS, macOS, Android, and limited Web platform projects.

Detailed development notes remain in [docs/CHANGELOG.md](docs/CHANGELOG.md).
