# Branding assets

`app-icon-light-1024.png` is the canonical, full-bleed default application
icon. `app-icon-dark-1024.png` is its dark-appearance counterpart.

Platform-specific sizes are generated from the light master. On iOS, the dark
master is assigned to the App Icon asset catalog's luminosity appearance so the
Home Screen can switch automatically.

The mark is original to Steam Account Companion. It does not contain the Steam
or Valve logo and must not be presented as an official Valve asset.
